# Capability

A term of the collection **Term** with every field type: text, multi-line text, select, yes/no,
date, list, and a hidden field `type`. The profile does not know the field `owner`; it stays
unchanged when properties are edited.

## Definition

A capability describes *what* is done, not *how*.

## Scope

A [value stream](value-stream.md) arranges capabilities in a sequence.
