# Unicode – characters from around the world

Accents and special characters: Ä Ö Ü ä ö ü ß é è ñ ç « » „ “ ‹ › – — … ° ± × ÷ € £ ¥ ©.

Emoji: 🎉 👩‍💻 🇨🇭 ✅ (several code points per character, important for columns and the cursor).

Other scripts: Ελληνικά, Русский, 日本語, 中文, 한국어, עברית, العربية.

Combining characters: e&#x301; is "é" made of two code points: é.

A very long word without a break opportunity:
Pneumonoultramicroscopicsilicovolcanoconiosisandotherverylongwordswithoutanybreak.
