# Welcome

This sample shows everything Lorequill can edit, display, and check. Each page has one topic, so
manual tests are quick to click through. All pages pass the profile's checks; pages with
deliberate errors are in the sample `samples/findings`.

## Syntax

- [CommonMark](syntax/commonmark.md): headings, paragraphs, emphasis, lists, quotes, code in every
  highlighted language, images, and raw HTML.
- [GitHub Flavored Markdown](syntax/gfm.md): tables, task lists, strikethrough, autolinks, and
  footnotes.
- [Material for MkDocs](syntax/material.md): admonitions, collapsible blocks, tabs, attribute
  lists, and snippets.

## Links and search

- [Link types](links/link-types.md): relative links, anchors, reference links, and external
  targets.
- [Architecture principles](architecture/principles.md) and [Identity](basics/identity.md): titles
  and aliases that differ from their file names. Type `](guidelines` in a link.

## Properties and collections

- Terms: [Capability](terms/capability.md) and [Value stream](terms/value-stream.md), and the
  retired term [Process map](terms/process-map.md), which keeps its id.
- Decisions: [DEC-1 Markdown as the source](decisions/dec-1-markdown.md).
- [Metadata schema](basics/metadata-schema.md): a page without a collection.

## Special cases

- [Long page](special/long-page.md) for scroll synchronization and the outline.
- [CRLF line endings](special/crlf.md), which are kept on save.
- [Unicode](special/unicode.md) with accents, emoji, and other scripts.

## Drafts and archive

- `drafts/data-product.md` is a parked draft: checked, but not published.
- The page `archive/old-glossary.md` is excluded in the profile and does not appear under
  **Pages**.
